# Sales and Technical Service System

This project is a **Sales and Technical Service System** that includes both a **Desktop Application** and a **Web Application**. The system is built using **.NET** technologies, **DevExpress** controls, and **ASP.NET Core** for the web part. It aims to provide a solution for businesses to manage their sales, technical services, and customer support efficiently.

---

## 🔗 Project Repositories

- 🖥️ **Desktop Application (WinForms)**:  
  [https://github.com/ParanovaFactory/Sales_And_Technical_Service](https://github.com/ParanovaFactory/Sales_And_Technical_Service)

---

## 🚀 Features

### Desktop Application (WinForms)
- **Sales Management**: Track and manage sales orders, invoicing, and payment processing.
- **Technical Service**: Manage technical service requests, service tickets, and customer support.
- **Inventory Management**: Manage products, spare parts, and stock levels.
- **DevExpress Controls**: A modern, user-friendly desktop interface powered by **DevExpress** controls.
- **Customer Management**: Record and manage customer information, including transaction history.
- **Reports and Analytics**: Generate reports on sales, service history, and inventory levels.

### Web Application
- **Framework**: ASP.NET MVC (Classic, .NET Framework)
- **Frontend**: Razor Views / HTML / CSS / JavaScript
- **Backend**: ASP.NET MVC
- **Database**: SQL Server
- **IDE**: Visual Studio 2022

## 🛠 Setup

### Desktop App
1. Clone the repo:  
   `git clone https://github.com/ParanovaFactory/Sales_And_Technical_Service`
2. Open in Visual Studio 2022.
3. Configure your DB connection string in `App.config`.
4. Build and run.

### Web App
1. Clone the repo:  
   `git clone https://github.com/ParanovaFactory/Sales_And_Technical_Service_Web_Page`
2. Open in Visual Studio 2022.
3. Setup database connection in `appsettings.json`.
4. Build and run using IIS Express or Kestrel.
